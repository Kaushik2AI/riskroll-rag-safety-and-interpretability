# Preliminary Prefix-Counterfactual Pilot

These are **pilot observations**, not final claims.

| Case | Natural error | Minimal correction | Pilot observation |
|---|---|---|---|
| Friday Night Lights | Permian wins | Dallas Carter wins | Downstream continuation changes substantially; strongest current causal-behavioral example |
| Champions League 2018 | Doja Cat | Dua Lipa | No downstream continuation window after the selected prefix |
| Baby's Day Out | Brian Haley played Baby Bink | Worton twins played Baby Bink | Model self-recovers in the natural condition; useful control |

## Interpretation

The pilot suggests heterogeneous behavior:
- some errors can persist and alter the continuation,
- some errors are followed by self-recovery,
- some candidate errors occur too late to provide a useful downstream window.

This motivates a larger validated set before mechanistic claims are made.
