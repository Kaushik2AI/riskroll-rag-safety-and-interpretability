| --- | --- | --- | --- | --- | --- | --- |
| FLARE / Active Retrieval Augmented Generation | 2023 | Active retrieval baseline / related work | Actively decides when and what to retrieve during long-form generation. | Retrieves during generation, but does not define a trusted semantic prefix or rollback unsafe committed claims. | RiskRoll controls claim commitment: unsupported claims are rolled back before entering the trusted prefix. | Implement as optional FLARE-style baseline if time permits; cite as key active-retrieval anchor. |
| Self-RAG: Learning to Retrieve, Generate, and Critique through Self-Reflection | 2024 | Self-reflective RAG related work / optional baseline | Trains a model to retrieve, generate, and critique using reflection tokens. | Uses learned self-reflection, but does not explicitly rollback the answer to the last trusted semantic prefix. | RiskRoll is an inference-time controller that separates candidate claims from trusted committed claims. | Cite as key self-critique RAG anchor; implement only if time and code availability allow. |
| CRAG / Corrective Retrieval Augmented Generation | 2024 | Closest retrieval-correction baseline | Evaluates retrieved document quality and triggers corrective retrieval actions when retrieval is poor. | Correction happens at retrieval-set level, not at the level of committing generated claims to a trusted prefix. | RiskRoll verifies claim-evidence support before semantic commitment and rolls back unsafe candidate spans. | Already implemented as CRAG-style evidence correction. |
| RARR: Researching and Revising What Language Models Say | 2023 | Closest post-hoc revision baseline | Finds attribution for generated output and post-edits unsupported content while preserving the original answer. | Repair happens after generation; unsupported claims may already have influenced later text. | RiskRoll prevents unsupported claims from entering the trusted prefix in the first place. | Our post-hoc correction baseline approximates this category; cite directly. |
| FActScore: Fine-grained Atomic Evaluation of Factual Precision | 2023 | Evaluation foundation | Breaks long-form generations into atomic facts and computes the percentage supported by reliable sources. | Evaluation framework, not a generation-time rollback method. | RiskRoll uses claim-level verification as an inference-time control action, not only as an evaluation. | Use to justify atomic-claim evaluation and supported-claim metrics. |
| LongFact / SAFE: Long-form factuality in large language models | 2024 | Long-form factuality evaluation anchor | Creates long-form factuality prompts and evaluates generated facts using a search-augmented factuality evaluator. | Evaluates factuality after generation; does not rollback unsafe claims during generation. | RiskRoll uses verification before commitment to prevent contamination while generating. | Use as public benchmark/evaluation candidate if implementation is feasible. |
| VeriScore: Evaluating factuality of verifiable claims in long-form generation | 2024 | Evaluation foundation for verifiable claims | Evaluates factuality in diverse long-form generation tasks containing verifiable and unverifiable content. | Evaluation metric, not rollback/recovery method. | RiskRoll actively manages which claims enter the trusted prefix. | Use to justify verifiable-claim-level evaluation. |
| ALCE: Enabling LLMs to Generate Text with Citations | 2023 | Best public dataset candidate | Benchmark for citation-aware generation with ASQA, QAMPARI, and ELI5. | Benchmark/evaluation setup, not a rollback generation method. | RiskRoll can be tested as a claim/citation commitment controller on citation-aware long-form QA. | Recommended next public benchmark adapter. |
| RAGChecker: Fine-grained Framework for Diagnosing RAG | 2024 | Diagnostic evaluation related work | Diagnoses retrieval and generation modules in RAG systems with fine-grained metrics. | Diagnoses RAG errors, but does not propose claim-level rollback control. | RiskRoll is an intervention/controller; RAGChecker is mainly diagnostic. | Cite for fine-grained RAG evaluation motivation. |
